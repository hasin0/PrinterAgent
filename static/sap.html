Before you start

A few things worth knowing.
  • Close SAP Logon first. SAP overwrites its own settings file when it closes, so it must not be running during setup. We will offer to close it for you.
  • Your existing settings are backed up. A dated copy is saved automatically before any change, so nothing is lost.
  • You must be on the refinery network. Connection tests will fail on home Wi-Fi or public networks — connect to the corporate LAN or VPN first.
  • SAP GUI must already be installed. If it is missing, raise a request with the IT Service Desk and we will deploy it to your PC.
